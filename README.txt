# Simple POS — iPad Offline POS

A deliberately simple, offline-ready point-of-sale web app.

## Included
- Tap products to build an order
- Quantity +/-
- Order notes
- Record payment method: Cash, EFTPOS, Bank transfer, Other
- Order list
- Order status: New, Preparing, Ready, Completed
- Today's sales and payment-method totals
- Add/delete products
- Business name
- Export/import backup
- Offline use after the app has been opened once online

## Important
This app RECORDS payments. It does not process a card/EFTPOS payment. The customer pays through your existing EFTPOS terminal; then you tap "EFTPOS" in the app.

## Recommended setup
Host these files on a free HTTPS static host (GitHub Pages is a good option), open the site once on the iPad while online, then add it to the Home Screen as a web app.

Data is stored locally on the iPad/browser. Use Settings > Backup & data > Export backup regularly.
